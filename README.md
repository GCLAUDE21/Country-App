# 🌍 COUNTRY APP

Projet interactif réalisé dans le cadre de ma formation Développeur Web.


## Objectif

Consommer une API REST en JavaScript natif et manipuler les données en temps réel : recherche par nom, filtrage par quantité via un slider, et tri par population ou ordre alphabétique.

## Démo Live



## Compétences travaillées

- Consommation d'API avec Fetch (async/await)
- Manipulation du DOM avec JavaScript natif
- Gestion des événements (input, click)
- Manipulation de tableaux (filter, sort, slice)

## Stack technique

JavaScript natif. HTML natif. CSS natif. Aucun framework ou bibliothèque externe.

## API utilisée

[RestCountries v3.1](https://restcountries.com)
